🔮 La Machine à Invocation

Une petite page web sur le thème du jeu de rôle : on entre son prénom, on choisit une créature, et elle répond à l'appel.

Projet réalisé pour le Kata Web 4 du Bloc 1 à Ada Tech School, pour réviser les bases du front : HTML, CSS et DOM.

Lancer le projet

1. Clone le repo :

   `bash`
   `git clone git@github.com:rbrochier/machine-a-invocation.git`

2. Ouvre index.html dans ton navigateur, directement ou avec Live Server.

Le script tourne dans le navigateur : il n'y a rien à installer, et il ne se lance pas avec Node.
